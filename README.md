# Playwright

This repository contains JavaScript basics and Playwright practice exercises.

## Contents

- `JSBasics/` - JavaScript learning files and assignments
- `dowhileloop.js` - do-while loop examples
- `package.json` - project metadata and scripts

## Purpose

This project is used for learning:
- JavaScript fundamentals
- loops and conditions
- variable declarations
- basic scripting
- Playwright-related practice files

## Clone

```bash
git clone https://github.com/sumilokesh09-jpg/Playwright.git
```

## Run files

You can open the JavaScript files in VS Code and run them using Node.js when needed.

```bash
node JSBasics/Assign1.js
```
